Verify your download

Every GitHub release includes checksums.txt. Download it alongside your package and verify the SHA-256 hash before installation.

sha256sum --check checksums.txt

Windows installers are currently unsigned. macOS packages are not signed or notarized, so the operating system may display security warnings. Verify the release source and checksum before proceeding.

Build from source

If you have Go installed, you can build both VSTodo executables from source:

git clone https://github.com/SneppX/vstodo.git
cd vstodo
go build -o vstodo .
go build -o vstodo-installer ./cmd/vstodo-installer

This builds the CLI and installer locally. Native packages and portable archives are the recommended installation method.
