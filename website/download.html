Universal (Go Install)

The simplest way to install VSTodo:

go install github.com/SneppX/vstodo@v0.1.2

        
This auto-places vstodo/vstodo.exe in your GOBIN and adds it to PATH.


        

          After installing:
          vstodo --version → vstodo version 0.1.2
          vstodo init → Initialize a new repository
