Version Control, Built Differently

VSTodo is an independent version-control system with Git-compatible interoperability. Manage repositories, branches, commits, merges, diffs, and more — entirely from the command line.

Download Documentation

Features

  • Full Git-compatible HTTP transport
  • Local object database with branches and commits
  • Unified content diff output
  • Merge and reset operations
  • Tag, branch, and checkout support
  • Hook system for custom workflows
  • GO-MOD ready: go install github.com/SneppX/vstodo@latest
