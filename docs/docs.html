Quick Start

  1. Install: go install github.com/SneppX/vstodo@latest
  2. Initialize: vstodo init (creates .vstodo/)
  3. Add files: vstodo add file
  4. Commit: vstodo commit -m "message"
  5. Check status: vstodo status
  6. View history: vstodo log

CLI Reference

  • vstodo init — Initialize a new VSTodo repository
  • vstodo add — Stage file contents to the index
  • vstodo commit -m — Record changes to the repository
  • vstodo status — Show working tree status
  • vstodo diff — Show unified content diffs
  • vstodo log — Show commit history
  • vstodo branch — List, create, or delete branches
  • vstodo checkout — Switch branches or restore files
  • vstodo merge — Merge changes from another branch
  • vstodo tag — Create, list, or delete tags
  • vstodo diff — Show unified diffs between commits/index/working tree
  • vstodo status — Show working tree status
  • vstodo reset — Reset current HEAD to the specified state
  • vstodo log — Show commit history
  • vstodo diff — Unified content diff output

Installation Guide

Option 1: go install (Recommended)

go install github.com/SneppX/vstodo@latest

This downloads the latest release and installs vstodo/vstodo.exe to your GOBIN directory, which should be in your PATH.

Option 2: Manual Binary

  1. Download the latest release from GitHub Releases
  2. Extract the archive (.zip for Windows, .tar.gz for macOS/Linux)
  3. Place the vstodo/vstodo.exe binary in a directory on your PATH
  4. Verify: vstodo --version

Verification

After installation, run:

vstodo --version
        vstodo -version
        vstodo status

All should output the version number (vstodo version 1.0.0) and status without error.
