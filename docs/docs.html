Quick start

Install VSTodo using a native package or portable archive from the latest release, then open a terminal in your project directory.

vstodo init
vstodo add README.md
vstodo commit -m "Initial commit"
vstodo status
vstodo log

Check the installed version and built-in help with vstodo --version and vstodo help.

Core commands

  • vstodo init [path] — Initialize a repository.
  • vstodo add <file> [file...] — Stage file contents.
  • vstodo commit -m <message> — Create a commit.
  • vstodo status — Show repository and staged state.
  • vstodo log [-n count] — View commit history.
  • vstodo diff [commit1 commit2] — Compare staged changes or commits.
  • vstodo show <object> — Inspect a repository object.
  • vstodo branch, checkout, merge, tag — Manage branches and history.

Advanced commands

VSTodo also includes reset, rebase, rm, fsck, blame, bisect, stash, cherry-pick, notes, gc, worktree, bundle, hash-object and cat-file.

Run vstodo help <command> for command-specific usage. See the complete command reference.

HTTP remotes and Git interoperability

Configure HTTP/HTTPS remotes with vstodo remote add, inspect refs with vstodo ls-remote, and use fetch, push and pull.

Remote push is currently fast-forward only. Force pushes, tag pushes and multi-ref pushes are not supported yet. Supply GitHub credentials through VSTODO_GITHUB_TOKEN or GITHUB_TOKEN; do not embed credentials in remote URLs.

For an existing Git repository, use vstodo adopt, then vstodo git-status, vstodo sync-git and vstodo export-git as appropriate. Adoption preserves the original Git object database and refs.

Build from source

Native packages and portable archives are recommended. If you have Go installed, you can build both executables from source:

git clone https://github.com/SneppX/vstodo.git
cd vstodo
go build -o vstodo .
go build -o vstodo-installer ./cmd/vstodo-installer

For platform-specific installation steps, see the Windows, macOS and Linux guides.
